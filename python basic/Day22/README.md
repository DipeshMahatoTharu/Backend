# Day 22 — Functions + Scope

Welcome to Day 22! Today we go deep into how Python handles functions, argument bindings, variables, and lexical scoping. You will learn the LEGB (Local, Enclosing, Global, Built-in) lookup rule, how nested closures capture environment state, and how functions behave as first-class objects in Python backend utilities.

---

## 🎯 Learning Objectives
By the end of today, you will be comfortable with:
- Gathering arbitrary arguments using `*args` and `**kwargs`.
- Tracing variable resolutions using the LEGB scoping rules.
- Writing nested functions and using lexical closures to preserve execution state.
- Passing functions as parameters to write modular, reusable utility components.
