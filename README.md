## 🛠️ How to Practice and Run Code

### Prerequisite
Make sure you have Python 3 installed. You can check this by running in your terminal/PowerShell:
```bash
python --version
```

### Running Files
To run any script (for example, the Day 20 OOP challenges), navigate to the project directory and execute:
```bash
python "python basic/Day20/testoop.py"
```

### Starting the OOP Practice Challenges
Once you are ready to complete your remaining practice tasks, go to the **[OOP_Practice/](file:///d:/Backend/python%20basic/OOP_Practice/)** folder and write your solutions inside each file. Each file contains clear requirements, a class structure, and pre-written test assertions to verify your work!
